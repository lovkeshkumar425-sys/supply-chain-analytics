# Supply Chain Analytics

## Project Overview
In this project, I analysed supply chain and delivery performance data using Python, SQL, and Power BI. The main aim was to understand delivery delays, shipping performance, sales, and profitability.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- SQL (MySQL)
- Power BI

## Key Analysis
- Analysed delivery status and late delivery risk.
- Compared actual shipping days with scheduled shipping days.
- Compared delivery performance across different shipping modes.
- Analysed regional and market-wise delivery performance.
- Explored sales and profit across product categories.
- Studied order status and monthly order trends.
